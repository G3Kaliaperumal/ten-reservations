# Experience cover photography

The JPEG files are locally bundled illustrative covers from
[Unsplash](https://unsplash.com), used under the [Unsplash License](https://unsplash.com/license).
They are visual context for a demonstration, not photographs or descriptions of
the actual inventory offering. They add no location, itinerary, price, or booking
condition to the source CSV data.

Images are served locally by Django. The source CDN provided 900 × 560 JPEGs;
there are no image API keys, hotlinks, or third-party requests in the application.
